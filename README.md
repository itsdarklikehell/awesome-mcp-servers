# awesome-mcp-servers

A collection of MCP servers.

A curated list of awesome MCP (Model Context Protocol) servers.

## What is MCP?

MCP (Model Context Protocol) is an open protocol that enables seamless integration between LLM applications and external data sources and tools.

## Servers

- [mcp-this](https://github.com/itsdarklikehell/mcp-this) - MCP server for this project
- [mcp-system-monitor](https://github.com/itsdarklikehell/mcp-system-monitor) - System monitoring MCP server
